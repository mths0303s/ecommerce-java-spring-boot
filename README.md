# 🛒 E-commerce Java + Spring Boot

Projeto de e-commerce inspirado em plataformas como o Mercado Livre, desenvolvido com **Java** e **Spring Boot**. 🚀

## 📌 Objetivo
Construir uma API/backend para marketplace com foco em:
- cadastro de usuários 👤
- anúncios de produtos 📦
- busca e filtros 🔎
- carrinho e pedidos 🛍️
- fluxo de pagamento 💳

## 🧱 Stack principal
- ☕ Java
- 🍃 Spring Boot

## 📂 Estrutura do projeto
Este repositório está em evolução. A ideia é organizar os módulos por domínio (usuários, produtos, pedidos, pagamentos e autenticação).

## ▶️ Como executar (quando a aplicação estiver completa)
1. Ter Java instalado (JDK 17+ recomendado) ✅
2. Clonar o repositório
3. Configurar variáveis de ambiente
4. Subir a aplicação com o comando do build tool do projeto (Maven/Gradle)

## 🧪 Testes
Os testes serão adicionados junto com a implementação dos módulos principais. ✅
